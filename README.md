# Pharmacovigilance ICSR Case Processing & Safety Assessment

A simulated Pharmacovigilance portfolio project demonstrating the end-to-end processing and assessment of Individual Case Safety Reports (ICSRs) using Microsoft Excel.

## Project Overview

This project demonstrates foundational skills relevant to entry-level Pharmacovigilance and Drug Safety roles.

The workflow covers:

1. Case Intake
2. ICSR Validation
3. Seriousness and Causality Assessment
4. Basic MedDRA Terminology Mapping
5. Case Narrative Writing
6. Quality Review
7. Safety Data Summary and Visualization

## Workbook Structure

| Sheet | Purpose |
|---|---|
| Case Intake | Captures simulated patient, reporter, drug and adverse-event information |
| Case Assessment | Performs ICSR validation, seriousness, expectedness, causality and follow-up assessment |
| MedDRA Coding | Demonstrates basic mapping from reported terms to medical terminology concepts |
| Case Narratives | Converts case information into structured safety narratives |
| Quality Review | Checks completeness, consistency and follow-up requirements |
| Summary Dashboard | Summarizes cases using KPIs and visual analysis |

## Key Project Outputs

- 10 simulated ICSRs processed
- 3 simulated serious cases
- 7 simulated non-serious cases
- 3 simulated high-priority cases
- 7 cases flagged for follow-up
- 10 cases meeting the simulated valid-ICSR criteria

## Important Note

All cases, patient information, drugs and outcomes in this project are fictional and created solely for educational and portfolio purposes.

This project does not contain real patient data and does not represent professional pharmacovigilance case processing.

MedDRA terminology should be verified against the applicable licensed/current MedDRA version when performing real-world coding.
